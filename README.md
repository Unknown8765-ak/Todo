📌 Project Title
Full Stack Todo Application
🚀 Overview

This is a full-stack Todo application built using modern web technologies.
The application includes secure authentication and complete CRUD functionality for managing tasks.

Users can:
Register and Login using JWT authentication
Create tasks
Update tasks
Delete tasks
Mark tasks as completed
Access protected dashboard routes

🛠 Tech Stack
Frontend
React (Vite)
Redux Toolkit
React Router
Tailwind CSS
Backend
Node.js
Express.js
MongoDB (Atlas)
Mongoose
JWT Authentication
Bcrypt for password hashing

🔐 Features

JWT-based authentication
HTTP-only cookies for security
Protected routes
Full CRUD operations
Clean scalable folder structure
Responsive UI
